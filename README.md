# India Used Car Advisor

Predicting used car prices in the Indian market using data analysis and machine learning.

## Status
Work in progress.

- [x] Load and clean the data
- [ ] Exploratory analysis and charts
- [ ] Feature engineering
- [ ] Train and compare models
- [ ] AI layer (plain-language input)
- [ ] Streamlit app

## Data
CarDekho used car dataset from Kaggle (manishkr1754/cardekho-used-car-data), about 15,000 listings. Cleaning steps: removed duplicates, rows with 0 seats, implausible km_driven values, and rows where km_driven equals selling_price (likely data-entry errors).
